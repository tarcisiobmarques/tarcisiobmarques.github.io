Política de Privacidade

Última atualização: 05/11/2026

1. Finalidade

O Rclone Backup Nextcloud é uma integração de uso pessoal que utiliza o software Rclone para realizar cópias de segurança de arquivos locais do Nextcloud para uma conta Google Drive autorizada pelo usuário.

2. Dados acessados

Mediante autorização OAuth, o aplicativo utiliza a API do Google Drive para acessar e gerenciar os arquivos e pastas permitidos pelo usuário.

3. Utilização dos dados

Os dados são utilizados exclusivamente para realizar e verificar cópias de segurança. O aplicativo não comercializa informações, não utiliza dados para publicidade e não os compartilha com empresas de publicidade.

4. Armazenamento e segurança

A integração é executada localmente no computador do usuário. As credenciais de autenticação são armazenadas na configuração local do Rclone. Os arquivos de backup permanecem na conta Google Drive autorizada.

5. Retenção e exclusão

Os arquivos permanecem no Google Drive até que o usuário os remova ou modifique sua configuração de backup. O usuário controla sua conta e os arquivos armazenados.

6. Revogação de acesso

O usuário pode revogar a autorização OAuth nas configurações de segurança de sua Conta Google.

7. Contato

Dúvidas sobre esta integração podem ser encaminhadas pelo perfil do responsável no GitHub.
