Rclone Backup Nextcloud

Aplicativo de uso pessoal destinado a realizar copias de seguranca de arquivos do Nextcloud para o Google Drive utilizando o Rclone.

Funcionamento

O aplicativo utiliza a API do Google Drive, mediante autorizacao OAuth do usuario, para transferir arquivos selecionados de um computador Linux para sua conta Google.

A ferramenta nao e disponibilizada como servico comercial e nao oferece acesso publico aos arquivos armazenados.
